Add the host-neutral `voyant.theme-development-runtime.v1` descriptor and an
additive connected-development Adapter seam to project-pinned Theme tooling.
Fixture development remains unchanged, while short-lived capabilities can be
inherited privately by the Astro child process without entering command
arguments, serializable descriptors, or build metadata.
Connected tooling can watch `theme.config` and its directly imported local
manifest modules, return structured validation reports for invalid edits, and
restart Astro with a validated replacement runtime descriptor.
The editor base URL is non-secret routing metadata; one-time editor handoff
codes remain outside the descriptor.
